# セレスティア

ミッションを達成して、キャラクター「セレスティア」を育てるタスク管理アプリ。
外部ライブラリなし。データはブラウザの localStorage にだけ保存される。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（HTML）|
| `style.css` | 見た目 |
| `app.js` | 動き |
| `manifest.json` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | Service Worker。オフラインで開けるようにする |
| `icons/` | アイコン4種（iPhone用・Android用・PWA用）|

## GitHub Pages に置く

**リポジトリ名は `celestia`（半角英字）にすること。**
GitHubのリポジトリ名に日本語は使えず、入力してもハイフンに置き換えられてしまう。
表示名としての「セレスティア」は `manifest.json` の中で設定してあるので、
ホーム画面のアイコン名はちゃんと日本語で出る。

1. GitHub で新しいリポジトリ `celestia` を作る。Public にする
2. このフォルダの中身を**そのまま全部**アップロードする（フォルダごとではなく、中のファイルを直接）
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
5. 1〜2分待つと `https://hitoki1103.github.io/celestia/` が開くようになる

## iPhone のホーム画面に置く

1. Safari で上のURLを開く
2. 下の共有ボタン（□に↑）
3. **ホーム画面に追加** → 「セレスティア」という名前で入る

以降は全画面のアプリとして開く。
**サイトを更新しても、ホーム画面のアイコンは置き直さなくていい。**
`sw.js` がネット優先の作りなので、次に開いた時点で新しい内容になる。

ただし次のものを変えたときだけは、一度削除して追加し直す必要がある。

- アイコン（`icons/apple-touch-icon.png`）
- アプリ名（`manifest.json` の `short_name`）

## 更新のしかた

書き換えて GitHub に push するだけ。
画面の並びは `index.html`、色や余白は `style.css`、動きは `app.js`。
大きく作り変えたときは `sw.js` の `CACHE` の値を `celestia-v2` のように上げると、
古いキャッシュがきれいに捨てられる。

## キャラクターについて

キャラクターは「セレスティア」で固定。アプリ側から名前も絵も変えられない。
名前は `app.js` の先頭にある `CHARA` にある。

代わりに、**設定 → あなたの名前** でユーザー自身の呼ばれ方を決められる。
これはレベルアップのときにセレスティアが呼びかける名前として使われる。

## データについて

キャラのレベルも記録も、その端末のブラウザの中にしか無い。
アプリ内の **設定 → バックアップ** から文字列をコピーして、
メモアプリなどに貼って残しておくと、消えても戻せる。
